# Динамическая отрисовка карт в процессе боя

## Описание реализации

Реализована полностью динамическая отрисовка блоков карт в процессе боя (startFight). Карты исчезают и их здоровье обновляется в реальном времени.

## Что было сделано

### 1. **Redux слайсы** (Store)

#### `fightUserCardsSlice.js`
- ✅ Добавлен экшен `removeUserCardByIdFromFight` - удаляет конкретную карту по ID при её гибели
- ✅ Добавлен экшен `updateUserCardHealth` - обновляет здоровье карты в реальном времени

#### `fightEnemyCardsSlice.js`
- ✅ Добавлен экшен `removeEnemyCardByIdFromFight` - удаляет конкретную карту врага по ID
- ✅ Добавлен экшен `updateEnemyCardHealth` - обновляет здоровье карты врага

### 2. **Компонент StartFight.jsx**

**Добавленные функции:**
- ✅ Импортированы новые Redux экшены для удаления и обновления карт
- ✅ При получении урона: `dispatch(updateUserCardHealth(...))` и `dispatch(updateEnemyCardHealth(...))`
- ✅ При гибели карты: `dispatch(removeUserCardByIdFromFight(...))` или `dispatch(removeEnemyCardByIdFromFight(...))`
- ✅ Добавлена задержка между раундами: `await sleep(1000)` (1 секунда) для наглядности процесса боя

**Процесс боя теперь:**
1. Карты получают урон → здоровье обновляется в Redux → FightPage перерисовывает карты
2. Карта гибнет → удаляется из Redux → исчезает со страницы
3. Пауза 1 сек → пользователь видит результаты раунда

### 3. **Компонент Card.jsx**

**Улучшения визуализации:**
- ✅ Добавлено отслеживание изменения здоровья через React `useState`

- ✅ Smooth transitions для всех изменений цвета и стилей

### 4. **Стили** (App.css)

Добавлены CSS анимации:

@keyframes fadeOutScale {

### 5. **Компонент FightPage.jsx**

Работает как есть - автоматически перерисовывает карты благодаря Redux реактивности!

## Как это работает

```
Раунд боя:
1. StartFight вычисляет урон
2. Обновляет здоровье в Redux через updateUserCardHealth/updateEnemyCardHealth
3. FightPage получает изменения → Card перерисовывает цвет здоровья
4. Если карта мертва → removeUserCardByIdFromFight/removeEnemyCardByIdFromFight
5. Redux удаляет карту из массива
6. FightPage перерисовывает сетку → карта исчезает
7. Пауза 1 сек → пользователь видит результаты
8. Следующий раунд
```

## Преимущества реализации

✅ **Полная реактивность** - карты обновляются автоматически через Redux
✅ **Плавные переходы** - CSS transitions для красивых эффектов
✅ **Наглядный процесс** - видно как меняется здоровье и гибнут карты
✅ **Хороший UX** - задержка между раундами позволяет следить за боем
✅ **Масштабируемость** - легко добавить новые эффекты или анимации
